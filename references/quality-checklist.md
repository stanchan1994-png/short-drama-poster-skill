# Quality Checklist

Use this checklist before final delivery or when reviewing generated posters.

## Must Pass

- 人物主体明确：核心人物脸部清晰，不能是远景小人。
- 画面主导明确：是否先判断了第一主导、第二主导和禁用误读，只使用人物/关系/道具/空间/符号/动作这六类抽象主导。
- 画幅比例明确：普通海报底图默认 2:3 竖版；如果用户指定其他比例，是否已按用户比例覆盖默认值。
- 无多余尺寸：除非用户明确要求 exact size，不要在平台词里写具体像素尺寸。
- 卖点角色明确：如果多个角色都是卖点，是否写清相对权重、同景别或接近景别、脸部清晰度和焦点关系。
- 人物关系可读：谁压迫谁、谁追逐谁、谁隐藏身份必须一眼能看懂。
- 标题安全区干净：默认位于下中窄幅区域；预留区域不能有复杂脸部、手、道具、强纹理或文字。
- 无画面内文字：除非用户明确要求，不能有汉字、英文、logo、水印、字幕。
- 商业海报质感：不是普通照片、截图、PPT封面、廉价拼贴或网感滤镜。
- 角色一致性：如果有角色三视图，轮廓、比例、材质、配色、发型、气质不能漂移。
- 参考生图优先：如果有角色三视图，不能为了“更好看”而擅自补写五官、肤色、年龄感、材质或发型设定。
- 服装不干扰：如果有角色参考图，平台词默认只写“服装造型按角色参考图，不重新设计服装”，不复述具体服装款式、颜色、材质、朝代、冠饰、甲胄或配饰。
- 角色完整性：如果用户提供多位命名角色参考且未标记可省略，是否全部进入主画面或已明确说明省略原因。
- 最新删除生效：用户删除的元素是否已从完整 prompt、平台 prompt、负向约束和 Workflow JSON 中彻底清除。
- 风格模式一致：不能一半写实、一半卡通，或人物与背景渲染语言割裂。
- 如果做带字版，标题必须可读且不遮挡主角关键五官。

## Composition Checks

- 单人海报：人物高度约 60%-80%，眼神和姿态承担主钩子。
- 双人海报：两人合计约 65%-85%，距离、朝向和光线体现关系。
- 三人海报：必须有单一视觉中心，避免三个人同权重并排站。
- 群像海报：主角最大、最亮、最清晰，配角形成层级而非平均排列。
- 四人及以上：只保证核心 2-3 人最清晰，其余角色服务关系，不要做毕业照。
- 关系主导：是否通过站位、朝向、视线、距离、遮挡和前后层级表达互动，而不是默认写牵手、伸手、拉扯或低头看物件。
- 道具主导：道具是否有结构、状态、位置、占比和受光，并且没有变成产品图。
- 空间/符号主导：空间或符号是否服务人物和关系，没有抢走人物脸部第一视觉。
- 动作主导：是否只有在用户明确要求动作场景时才启用。
- 场景只能服务剧情，不要用大空景掩盖人物关系。
- 已选方向精修：如果用户已经进入控图阶段，是否只精修一个方案，而不是继续泛化新方向或主动给更短版。
- 人物和关键道具占比：主体是否足够大，远景、天空、纯黑区域是否挤占了卖点。
- 后排角色落位：后排或侧边角色是否有脚下接地、遮挡关系、光照连接和空间锚点，不能像悬空立牌。
- 标题安全区：是否默认放在下中窄幅区域；只有特殊构图、平台格式、带字设计或参考排版明确需要时才改到上方/侧边。
- 标题安全区可用性：安全区是否是可用窄幅，而不是下半张或大块区域变成死黑。
- 大型背景符号：符号、屏幕、天体、投影或建筑形体是否服从同一镜头透视、消失线和前后遮挡，而不是平面贴图。
- 画幅异常：是否避免了超窄长图、手机长截图比例、超过 1:2 的细长竖幅，除非用户明确指定。

## Visual Polish Checks

- 光影有主光、轮廓光和背景分离。
- 写实控图场景是否写清统一光照体系：主光方向、辅光或轮廓光、实际光源、地面反光、空气雾层、接地阴影和边缘融合。
- 背景层次清楚，但不过度堆道具。
- 皮肤真实精修，不塑料。
- 服装、道具和空间符合题材时代。
- 缩略图尺寸下仍能读出人物和冲突。
- 车辆、建筑、机械或大件道具是否承担空间锚点、光源、尺度或叙事功能，而不是单独广告式展示。
- 氛围加强是否优先通过雾、水汽、蒸汽、雨雾、湿地反光、烟霾、前景灯斑或边缘光完成，而不是随意加新主体。

## Turnaround Checks

- 有角色三视图时，提示词是否先锁定“角色三视图一致性优先”，而不是先写审美美化。
- 是否避免了会改设定的描述，比如改脸、改比例、改材质、改种族特征、改配色、改年龄感。
- 是否主要通过表情、视线、姿态、道具、景别、站位和布光来制造戏剧性，而不是通过服装扩写制造差异。
- 如果角色不像，是否先删掉多余外貌词，而不是继续叠加更多审美词。
- 如果三视图本身信息不足，是否保持短描述，而不是脑补新设定。
- 如果用户预告会提供角色图，是否避免提前写死外貌、年龄、发型、服装、材质、配色或物种/类型细节。
- 平台词是否避免了具体服装名、颜色、材质、朝代标签、冠饰、首饰、甲胄、长袍、制服等会诱发重设计的词，除非用户明确要求保留这些识别点。

## Style-Reference Checks

- 是否区分了“角色三视图”和“风格/构图参考图”，而不是统一当作内容参考图处理。
- 是否只继承了构图、景别、留白、光影、色调和完成度，而没有继承参考图中的人物身份。
- 是否明确排除了参考图中的剧名、标题文案、logo、水印、二维码和平台元素。
- 如果风格图里有人物，是否抽象成站位关系和层级，而不是把对方的脸、服装、饰品直接写进 prompt。
- 如果风格图里有强剧情道具，是否避免把它误写成当前故事的道具设定。
- 如果有动作/关系参考图，是否只继承姿态、动线、受力方向、接触关系、镜头角度和前后层级。
- 是否避免继承动作参考图中的角色身份、类型或物种、气质、年代感、职业感、风格质感、配色、材质、道具、文字和原图剧情。
- 高动态动作是否写清镜头角度、重心、肢端位置、运动方向、表情状态和动势模糊边界。
- 多轮修订中，是否只保留最新用户纠正，没有混写旧名称、旧姿态、旧材质或旧构图。
- 用户进入精准控图阶段后，是否停止主动输出短版、压缩版或新方向，转而强化镜头、占比、站位、光照、透视和空间锚点。
- 如果有虚影、全息、能量态、阴影或剪影，是否同时写清保留内容、透明度、边缘、内部结构、消散方式和实体/非实体状态。
- 辅助设定元素是否没有抢走用户指定的第一视觉焦点。
- 如果有本体、化身、召唤体、镜像、灵体或对应体等身份关系，是否没有把关系误写成外观变异或错误关系设定。
- 多角色或分层构图是否有统一光源、色温、空气透视、接地/遮挡、比例关系和边缘融合。
- 非人、机械、物件或强设计角色是否锁定可见的高漂移局部识别点。
- 扩图/改比例任务是否明确目标比例，并保持主体、姿态、表情、设计、光影和构图中心不变。

## Prompt-Cleanliness Checks

- 平台投喂版 Prompt 里是否完全没有 `你给的`、`你提供的`、`如果你要`、`我可以`、`下面给你` 这类对话残留。
- 平台投喂版 Prompt 里是否没有图片文件名、附件名、本地路径、编号式文件引用或原始参考标签。
- 是否避免了“视觉上让人一眼明白这是……”这类解释句，而改成直接画面指令。
- 是否避免了“必须严格参考”“应该改成”这类监督口吻，而改成具体可见约束。
- 是否避免了“改为”“改成”“保持为”“参考示例图”这类修订态表述，而改成最终结果态表述。
- 平台投喂版 Prompt 是否只包含画面内容、构图、光影、材质和负向约束。
- 平台投喂版 Prompt 是否控制在 1900 字以内。
- 压缩后是否仍保留角色权重、景别、脸部清晰度、参考图锁定、主构图、主光影和高风险负向约束。

## Style-Specific Checks

- 写实模式：皮肤和五官不能有明显 AI 塑料感，材质细节要真实。
- 半写实插画：不能既像照片又像低端 CG，笔触和体积关系要统一。
- 动漫卡通：五官比例、线条风格、发型轮廓必须统一，不能混入写实皮肤语言。
- 类3D动漫：人物要有三维体积和材质高光，但不能变成玩偶、手办或廉价手游宣传页。

## Typography Checks

- 主标题在缩略图下仍能读清。
- 标题位置与标题安全区一致。
- 标题不能压住主角眼睛、嘴部、核心道具。
- 标题风格与题材一致，不出现错字和乱码。
- 默认只出现剧名；副标题、slogan、平台角标必须是用户主动要求才加。
- 主标题与副标题层级明确，不要同等重量。
- 字体特效不能比人物关系更抢眼。

## Common Fixes

- 人太小：要求中近景/半身/膝上构图，人物占比提高到 65%-80%。
- 关系不清：加入对峙、背身回望、距离压迫、手持关键道具或空间阻隔。
- 太廉价：去掉拼贴、霓虹渐变、网红滤镜和无意义光斑，改用电影布光和真实材质。
- 卡通感不稳：明确是赛璐璐、平涂、半写实插画还是类3D动漫，不要混搭。
- 群像像合照：压缩次要角色数量，拉开前后层次，重新设定主角最亮最大。
- 群像一致性被热闹感挤掉：先恢复角色绑定、外观一致性和层级，再加喜剧感、夸张动作或背景信息。
- 卖点角色太弱：提高其景别、脸部清晰度、亮度或前中景位置，明确它与主角同景别或接近景别。
- 类3D动漫太像手游：减少悬浮粒子、廉价紫蓝特效和过度金属高光，强调高级 key visual 质感。
- 标题区脏：默认在下中留出干净窄幅区域，不放脸和强纹理；只有特殊构图才改到上方或侧边。
- 带字版太乱：先做无字底图，再单独写标题层说明；默认只保留剧名，缩短标题，减弱发光和描边。
- 角色不像：减少参考版本数量，绑定角色名，强调角色三视图一致性优先于风格。
- 角色被写变样：删除多余外貌美化词和具体服装词，只保留角色三视图锁定句、服装造型按参考图不重设计、表情、姿态、站位、景别和光影描述。
- 服装被重设计：删除具体款式、颜色、材质、朝代、冠饰、甲胄、披风、长裙、制服等词，改为 `服装造型按角色参考图，不重新设计服装`。
- 风格图被抄内容：删掉从参考图反推来的剧名文字、人物描述、服装道具和平台元素，只保留构图、景别、留白和布光信息。
- 动作图被抄内容：删掉从动作图继承来的角色身份、气质、年代感、职业感、风格质感、颜色、材质、道具和剧情，只保留姿态、动线、受力关系、镜头和层级。
- 动作不稳：补镜头角度、重心、肢端位置、运动方向、表情状态和动势模糊边界。
- 旧设定回流：删除旧名称、旧姿态、旧材质和旧构图，只保留最新用户明确纠正后的版本。
- 虚实状态混乱：同一句写清保留的设计识别点和变化后的材质状态，例如颜色是否保留、透明度、边缘、内部结构、是否实体。
- 辅助元素抢焦点：降低尺寸、亮度、清晰度、对比度或后移空间层级，除非用户指定它是主视觉。
- 身份关系被误写成外观变异：保留各自参考图设计，用站位、视线、距离、光影呼应或构图层级表达关系。
- 口语直塞：把用户口语改写成可见动作、视线、距离、接触、动线、站位、光影或层级。
- 多人像拼贴：补统一主光、色温、空气透视、阴影方向、遮挡关系、比例尺度和边缘软硬。
- 光照不融合：把人物、背景、道具统一到同一主光方向和色温，补实际光源、地面反光、接地阴影、空气雾层和边缘受光。
- 透视不一致：明确镜头高度、轻微倾斜或水平状态、消失线方向，并要求大型符号、建筑、地面和人物服从同一透视。
- 大型符号像贴图：补体积厚度、空间雾遮挡、边缘散光、与人物局部重叠和亮度低于主脸部。
- 大件道具突兀：把它后移或侧移，改成光源、空间支点、尺度参照或剧情线索，避免完整广告式亮相。
- 后排人物悬空：给脚下接地、靠近车辆/墙体/门框/台阶等锚点，并补遮挡、阴影和同色温受光。
- 标题区死黑：缩小安全区，保留前景雾气、湿地反光、暗部纹理和失焦灯斑。
- 比例跑偏：在平台词开头写明 `2:3 竖版海报比例`，并加入不要超窄长图、不要手机长截图比例。
- 动作不合角色：删除不符合服装结构或容易产生歧义的手势，改用站姿、步伐、视线、肩颈角度、持物方式或共同危机朝向。
- 互动弱：同时调整视线、朝向、距离、遮挡、前后层级和共同事件链，不只改表情词。
- 局部识别点漂移：为非人、机械、物件或强设计角色补脸部纹理、色块边界、眼周、鼻口/前端结构、耳角尾肢端和特殊标记等局部锁定。
- 扩图改坏主体：改为只延展边缘环境和留白，明确目标比例，禁止新增主体、改脸、改服装、改姿态或移动构图中心。
- 词变味：删除所有对话指代、解释句和监督口吻，把句子改回纯画面指令和负向约束。
- 词带修改痕迹：删除 `改为/改成/保持为/参考示例图`，直接改写成最终画面已经成立的结果态句子。
- 词太长：先删重复形容词，再合并负向约束，最后压缩过渡语，但不要删角色权重、景别、脸部清晰度、参考图锁定、构图、光影和关键识别点。
