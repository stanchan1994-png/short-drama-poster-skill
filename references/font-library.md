# Font Library

Use this file when the user wants to reverse-engineer Chinese short-drama title styles from references, classify title samples, or choose a title direction before adding material effects.

This library separates:

- base glyph structure: the core drawing logic, stroke model, and silhouette
- material treatment: metal, gold foil, embossed, brushed, ink-dry, glow, enamel, sticker, and so on

Always identify the base glyph structure first. Then match the surface material to the poster genre, emotional temperature, and production level.

## Classification Method

For each new sample, record:

- name
- sample file
- base glyph structure
- stroke traits
- structural mood
- material treatment
- best-fit genres
- genres to avoid
- replacement style keywords
- prompt keywords

## Working Rule

When the user gives new title references:

1. classify the base glyph structure first
2. decide whether it matches an existing family
3. only create a new family if the structure is truly different
4. assign material treatment last based on poster genre

Do not confuse:

- writing energy with material texture
- calligraphy with frenzy handwriting
- premium elegance with weak readability
- comedy softness with childish low-end execution
