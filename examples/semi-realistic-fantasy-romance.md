# Example: Semi-Realistic Fantasy Romance

## Input Brief

- 类型：玄幻爱情 / 命运羁绊
- 角色：女主、男主
- 需求：半写实插画海报，梦幻但不能廉价
- 标题安全区：右上

## Recommended Direction

- 方向名：月下命契
- 风格模式：半写实插画
- 构图：双人靠近
- 适合原因：适合强调暧昧、宿命、禁忌感，能保留商业海报完成度又不必完全写实

## Chinese Complete Prompt

中文短剧竖版商业海报底图，半写实插画海报，人物关系一眼可读。画面为双人靠近构图，女主与男主合计占据画面约 70%，女主位于前景偏右，长发被夜风带起，抬眼看向男主，神情克制又动摇；男主位于左后侧，微微低头靠近，披深色长袍，手腕间隐约有命契光纹连接到女主手指。场景设置在月夜高台与云海之间，可见残破栏杆、飘落符纸、远处山门与轻雾层次，背景只保留服务剧情的幻想元素。镜头为半身中景，人物脸部清晰，表情体现宿命牵引与危险亲密。光影采用银蓝月光加暖色微弱反射光，整体氛围清冷、梦幻、压抑。材质细节包括发丝笔触、布料层次、皮肤柔和过渡、云雾体积光和玉石微光。保留右上标题安全区干净留白，方便后期添加剧名。如果是写实或半写实，材质细节包括服装、皮肤、玉石和雾气层次。不要生成任何可见文字、汉字、英文、logo、水印、字幕、平台标识；不要廉价拼贴、不要网红滤镜、不要低清模糊、不要畸形手指、不要重复人物。
