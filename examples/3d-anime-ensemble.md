# Example: Stylized 3D Anime Ensemble

## Input Brief

- 类型：豪门 / 复仇 / 群像
- 角色：女主、男主、反派长辈、弟弟角色、秘书角色
- 需求：类 3D 动漫海报，像高级 key visual，不要像廉价手游启动图
- 标题安全区：上方

## Recommended Direction

- 方向名：豪门阶梯式压迫
- 风格模式：类3D动漫
- 构图：五人阶梯群像
- 适合原因：这类风格更适合做高辨识度阵营关系图，既有商业冲击力，也能承载 5 人信息量

## Chinese Complete Prompt

中文短剧竖版商业海报底图，类3D动漫海报，高级三维动漫渲染，人物关系一眼可读。画面为五人阶梯群像构图，女主位于最前景中央略偏左，微抬下巴，黑色礼服与冷光交界处形成核心视觉；男主站在她后方半步，肩线更高，眼神克制但保护意味强；反派长辈位于高阶平台正后方，体量最大但清晰度略低于双主角，用俯视姿态制造压迫；弟弟角色与秘书角色分列两侧作为第二层信息，形成家族与利益阵营。五人合计占据画面约 82%，双主角最亮、最清晰，反派次之，其余角色只承担关系补充。场景设置在豪门宴会厅与大理石旋转楼梯之间，可见吊灯虚化、高窗冷光、金属扶手、玻璃杯冷反光和红酒暗色点缀。镜头为中近景略仰视，人物脸部干净，眼神明确，表情体现隐忍、威压、试探与反杀前夕的危险平衡。光影采用冷主光加金色轮廓高光，整体氛围高压、华丽、锋利。如果是类3D动漫，则强调动漫角色比例、清楚发丝块面、面部干净、眼神设计明确、布料与金属高光高级、体积光和轮廓光清晰，但不要塑料玩偶感，不要廉价手游登录页感。保留上方标题安全区干净留白，方便后期添加剧名。不要生成任何可见文字、汉字、英文、logo、水印、字幕、平台标识；不要廉价拼贴、不要低清模糊、不要重复人物、不要玩偶塑料感、不要过度浮夸特效。
