# Example: Anime / Cartoon Family Secret

## Input Brief

- 类型：轻悬疑 / 家族秘密 / 青春感
- 角色：女主、男主、母亲角色
- 需求：动漫卡通海报，人物关系清楚，不能像儿童插画
- 标题安全区：下中

## Recommended Direction

- 方向名：雨夜家门口的真相
- 风格模式：动漫卡通
- 构图：三人三角张力
- 适合原因：三人关系能直接建立“主角组 + 家族阻隔”的视觉矛盾，动漫风格更适合年轻向传播

## Chinese Complete Prompt

中文短剧竖版商业海报底图，动漫海报风格，人物关系一眼可读。画面为三人三角张力构图，女主站在画面前方偏中，短暂停步回头，眼神震惊而倔强；男主站在她身后偏左，身体前倾像在保护她；母亲角色站在高一级台阶上偏右，俯视两人，手持旧照片，形成压迫与秘密感。三人合计占据画面约 78%，主角二人最清晰，母亲角色作为第二层视觉中心。场景设置在雨夜别墅门厅外，可见门灯、湿地反光、旧照片、半开的雕花门和冷暖对冲光线。镜头为中景平视，人物脸部清晰，表情体现质问、隐瞒和家庭阻隔。光影采用冷雨夜主光加门内暖光反差，整体氛围悬疑、压迫、青春冲突。如果是动漫卡通，则强调清晰轮廓、统一五官风格、赛璐璐明暗、发型块面、眼神设计和角色站位对关系的说明。保留下中标题安全区干净留白，方便后期添加剧名。不要生成任何可见文字、汉字、英文、logo、水印、字幕、平台标识；不要廉价拼贴、不要低幼儿童插画感、不要崩脸、不要比例失衡、不要重复人物。
